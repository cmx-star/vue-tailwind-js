## 💡 技术栈概览

本项目采用以下技术栈:

| 技术         | 版本  | 用途     |
| :----------- | :---- | :------- |
| Vue 3        | ^3.x  | 前端框架 |
| Vite         | ^5.x  | 构建工具 |
| Tailwind CSS | v4    | 样式框架 |
| Vue Router   | ^4.x  | 路由管理 |
| Pinia        | ^2.x  | 状态管理 |
| Vue I18n     | ^10.x | 国际化   |

**开发模式:** Options API  
**组件注册:** 自动注册 (`unplugin-vue-components`)  
**路由模式:** 动态路由 + 自动加载  
**主题系统:** CSS 变量 + Tailwind v4
